# LegioSoft.Imaging.SVG

`LegioSoft.Imaging.SVG` provides SVG parsing and rendering support for the LegioSoft.Imaging ecosystem.

## Features

- Parse common SVG 1.1 elements
- Render SVG content with SkiaSharp
- Support shapes, paths, text, gradients, transforms, and clip/mask features
- Target .NET 6.0 through .NET 10.0

The NuGet package includes this README and project metadata for publishing.
